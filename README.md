# 大连 · 沈阳随身旅行攻略

面向手机的五日旅行手册，包含真实地图、逐站行程、打车与地铁对比、40张餐饮参考图、24张景点参考图，以及无辣点单、穿搭和突发情况方案。

网站：https://michael-zacharie.github.io/dalian-shenyang-trip/

静态页面从 main 分支根目录发布。订单、地址和进度仅保存在访问者自己的浏览器 localStorage 中，不上传到仓库。

费用、营业和天气以出发时核对为准。图片在线引用原始来源，作者保留权利；每张图在网页中附有来源与适用范围。地图使用 Leaflet 和 OpenStreetMap，并保留署名。
